Mollie Remote Payment Client
============================

Version 2.1.1

1. Install this plugin on the WooCommerce store.
2. Open WP Admin > Mollie Remote Payment.
3. The payment collection server is already set to https://carrycubes.com.
4. Enter the exact same Shared Secret used on the server plugin.
5. Mollie payment descriptions are sent from this client as "Cubes".
5. Open WooCommerce > Settings > Payments and enable "Mollie Remote Payment".
6. Set the checkout title/description as desired.
7. Use the Test Connection button before placing an order.

The WooCommerce order currency must match the server plugin currency.
